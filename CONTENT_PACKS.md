# BlackQuill Content Packs

From v0.74 onward, the main ZIP contains only the core application.

Optional graphics, icon packs, banners, styles, and sample campaign assets are shipped separately as content packs.

To install a content pack, extract it into your shared data folder:

```text
../blackquill-common-data/
```

Typical content pack folders:

```text
blackquill-common-data/system/images/banners/
blackquill-common-data/system/icons/<pack-name>/
blackquill-common-data/system/styles/
```
